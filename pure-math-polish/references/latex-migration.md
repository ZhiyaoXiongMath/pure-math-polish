# LaTeX 迁移检查

## 先定义所选范围

先建立仅做格式与宏迁移的中间稿，检查数学内容，再做语言与结构编辑。用户只改局部或明确保留原模板时，不迁移全篇。不要用字体或页数相似代替字面代码检查。

从所选原始论文检查有效设置：class、选项、字体、页面、行距、正文后的覆盖、页眉页脚、目录、章节及书目。保留目标稿件的题名、署名、单位和致谢。只引入当前稿件需要的包和宏，不复制未使用的字母表、调试定义和多余计数器。

## 编号和环境

近期 HYM 论文中可以直接核对这些配对：

```tex
\btheorem ... \etheorem
\bproof ... \eproof
\beq ... \eeq               % equation
\be ... \ee                 % eqnarray*
\bd ... \ed                 % enumerate
```

编号 `eqnarray` 不等于 `eqnarray*`。保留 label、counter 依赖、引用与已有编号，不能为了相同短宏而去掉编号，也不机械将 align/cases 全改成 eqnarray。简单不编号公式可沿用原稿与所选源码都支持的表达。

定理别名只包装相应环境，不夹带全局不可分页逻辑或第二套计数。局部确有断页问题时作最小修复，重编译并检查受影响页面；不靠缩小字号或负间距掩盖问题。

## 数学宏与冲突

先比较定义和参数，再检查实际、间接调用和作用域。`macro_conflicts.py` 只报告词法差异，不证明语义不同，也不自动重写。

| 命令类别 | 迁移前要确认的内容 |
|---|---|
| `\ddbar` | 定义是否含有虚数因子、常数和次序；不可按同名直接覆盖 |
| `\vol`、`\Vol` | 是否自带度量下标；避免重复或改变体积形式 |
| `\bar`、`\tilde`、`\hat`、`\phi` | 原稿是否用不同字形区分对象；有区别时不能全局合并 |
| `\p`、`\bp`、`\sq`、`\ts`、`\om` | 原名是否已表示其他对象；新定义与全部调用是否一致 |
| `\id`、算子缩写 | 大小写、直立字形和数学作用对象是否一致 |
| `\>` | 原生间距命令是否在稿内使用；不能无意替换成箭头 |
| Laplacian 与曲率宏 | 实复归一化、正负号、升指标及乘法方向是否相同 |

不要仅因一个定义没有直接正文调用就删除它；还要排除其他宏、类、样式和包含文件中的间接使用。遇到冲突时可以保留本稿必要的专用宏，并在稿外说明例外，而不是悄改数学。

使用 `newcommand`、`renewcommand` 或 `DeclareMathOperator` 的方式，按所选源稿及实际包提供情况决定。作者源码里的重复覆盖顺序可以整理，但必须保留最终意义；不能把“更现代的写法”未经授权替换成个人偏好的另一套风格。

## 验收

分别检查字面代码、有效排版和数学含义。`profiles/hym-amsart.json` 记录从主原稿提取的检查依据，不是另一个 TeX 模板。未调用的可选宏可以不定义；定义过或实际使用的相应宏须检查。计数器、有效重定义和跨文件调用仍需人工审查。

保留原始源码与新稿的可审查 diff。源码修改后构建最后 PDF，检查首页、奇偶页、页眉、目录、长公式、主要定理、页间断点和书目。模板迁移允许改变页数，但不能改变数学含义或用过期 PDF 交付。
